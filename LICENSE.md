## Authorship & Attribution

This application was built by **Claude**, an AI model created by
**Anthropic**, using material provided to it and under the guidance of
**Keith Francis, GitHub username keithintrinidad**.

**Parish of the Assumption**, supplied by Keith Francis. Additional
